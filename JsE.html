Simulador Interactivo de JavaScript

Una aplicación web interactiva en vivo donde puedes ver reflejados conceptos de variables, objetos, arreglos, condicionales, eventos y DOM.

1. Lógica del Script Interactivo

Este código maneja el estado global, la captura de eventos del usuario, filtros con métodos de arreglos y renderizado dinámico en el DOM:


// Estado inicial (Variables, Objetos y Arrays)
let alumnos = [
    { id: 1, nombre: "Carlos Pérez", edad: 20, calificacion: 85 },
    { id: 2, nombre: "Ana Gómez", edad: 17, calificacion: 92 },
    { id: 3, nombre: "Luis Torres", edad: 22, calificacion: 78 }
];

// Funciones flecha y condicionales
const esMayor = edad => edad >= 18;
const obtenerEstado = cal => cal >= 90 ? "Sobresaliente ⭐" : "Aprobado ✅";

// Función asíncrona simulando guardado en servidor
async function guardarEnServidor(nuevoAlumno) {
    return new Promise(resolve => {
        setTimeout(() => {
            alumnos.push(nuevoAlumno);
            resolve(true);
        }, 800);
    });
}
