Apuntes Completos de HTML

Guía estructurada y exhaustiva sobre el lenguaje de marcado, organizada por categorías temáticas y normativas del estándar web.

¿Qué es HTML y para qué sirve?

HTML (HyperText Markup Language o Lenguaje de Marcado de Hipertexto) es el lenguaje de programación estándar utilizado para crear y estructurar páginas web. A través de un sistema de "etiquetas" (tags), le indica a los navegadores web (como Chrome, Firefox o Safari) cómo deben mostrar los textos, imágenes, videos y enlaces en la pantalla.

¿Para qué sirve? Su función principal es proporcionar la estructura y esqueleto de un sitio web. Mientras que CSS se encarga del diseño visual y estético, y JavaScript de la interactividad y la lógica, HTML define qué elementos existen en la página (párrafos, títulos, tablas, formularios) y cómo se relacionan entre sí jerárquicamente. Sin HTML, la web tal como la conocemos no podría existir.

1. Estructura base del documento

Elementos fundamentales necesarios para inicializar cualquier archivo HTML e informar al navegador sobre su codificación y metadatos.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Título</title>
</head>
<body>
    <!-- Contenido -->
</body>
</html>
<!DOCTYPE html>

Define el tipo de documento para HTML5.

<!DOCTYPE html>
<html>

Contenedor raíz de toda la página web.

<html lang="es">...</html>
<head>

Almacena metadatos invisibles, enlaces CSS y títulos.

<head>...</head>
<title>

Establece el título de la pestaña del navegador.

<title>Mi Web</title>
<body>

Agrupa todo el contenido visual y estructurado visible.

<body>...</body>
<meta>

Proporciona metadatos estructurados (codificación, viewport).

<meta charset="UTF-8">

2. Formato de texto y párrafos

Etiquetas encargadas de estructurar bloques de texto, jerarquías de títulos y realces tipográficos de manera semántica.

<h1> a <h6>

Encabezados o títulos jerárquicos (del nivel 1 al 6).

<h1>Título Principal</h1>
<p>

Define un bloque de párrafo de texto estándar.

<p>Texto descriptivo.</p>
<br>

Inserta un salto de línea simple dentro del flujo.

Linea 1<br>Linea 2
<hr>

Genera una línea temática horizontal de separación.

<hr>
<strong> / <b>

Resalta texto con importancia fuerte (negrita).

<strong>Importante</strong>
<em> / <i>

Enfatiza texto en cursiva o itálica.

<em>Cursiva</em>
<sup> y <sub>

Superíndices y subíndices para fórmulas o notas.

x<sup>2</sup>
<div> y <span>

Contenedores genéricos en bloque y en línea respectivamente.

<div>Bloque</div>

3. Listas

Estructuras orientadas a organizar colecciones de elementos de forma secuencial, desordenada o descriptiva.

<ul>

Crea una lista desordenada (con viñetas circulares).

<ul><li>Elemento</li></ul>
<ol>

Crea una lista ordenada numéricamente o por letras.

<ol><li>Paso 1</li></ol>
<li>

Representa un elemento individual dentro de listas (ul/ol).

<li>Ítem de lista</li>
<dl>, <dt>, <dd>

Lista de definición (término y su respectiva descripción).

<dt>HTML</dt><dd>Lenguaje...</dd>

4. Enlaces y elementos multimedia

Herramientas de hipertexto para conectar recursos externos/internos e incrustar contenido gráfico y audiovisual.

<a>

Etiqueta de hipervínculo para navegación interna o externa.

<a href="url">Enlace</a>
<img>

Inserta imágenes gráficas (PNG, JPG, SVG).

<img src="img.jpg" alt="Foto">
<audio>

Reproductor nativo de archivos de audio integrados.

<audio src="audio.mp3" controls></audio>
<video>

Reproductor nativo e interactivo de secuencias de video.

<video src="vid.mp4" controls></video>
<embed> / <object>

Incrustan complementos, objetos externos o contenidos multimedia antiguos.

<embed src="file.swf">
<bgsound>

Reproduce sonido de fondo automático (heredado de entornos legacy).

<bgsound src="audio.wav">

5. Tablas

Estructuras tabulares organizadas en filas, columnas y celdas para representar datos estructurados.

<table>

Contenedor principal que engloba toda la estructura de la tabla.

<table>...</table>
<tr>

Define una fila horizontal de celdas dentro de la tabla.

<tr><td>Fila</td></tr>
<td>

Celda estándar de datos tabulares.

<td>Dato de celda</td>
<th>

Celda de cabecera (texto resaltado y centrado por defecto).

<th>Encabezado</th>
<colgroup> <col>

Agrupa columnas para aplicarles estilos o formatos comunes.

<colgroup span="2">

6. Formularios e interactividad

Elementos orientados a la recolección de datos, interacción del usuario y envío de peticiones.

<form>

Contenedor principal del formulario interactivo.

<form action="envio.php">
<input>

Campo multifuncional de entrada (texto, password, checkbox, radio).

<input type="text" name="usuario">
<textarea>

Caja de texto multilínea para comentarios extensos.

<textarea rows="4"></textarea>
<select> y <option>

Crea menús desplegables con opciones seleccionables.

<select><option>Opción</option></select>
<button>

Botón interactivo accionable (envío, reseteo o propósito general).

<button type="submit">Enviar</button>

7. Mapas de imagen y Marcos (Frames)

Técnicas clásicas de partición de pantalla y zonas interactivas geométricas sobre imágenes.

<map>

Define un mapa de imagen interactivo asociado.

<map name="red">...</map>
<area>

Especifica las coordenadas geométricas (círculo, rectángulo, polígono) en un mapa.

<area shape="rect" coords="...">
<frameset>

Estructura contenedora para dividir la ventana en filas o columnas de marcos.

<frameset cols="20%,*">
<frame>

Define un marco individual independiente dentro de un frameset.

<frame src="pagina.html">

8. Nuevas etiquetas de HTML 4.0

Elementos introducidos para mejorar la semántica, control de formularios avanzados y accesibilidad.

<q>

Cita textual corta en línea.

<q>Esto es una cita</q>
<acronym>

Define un acrónimo o abreviatura de texto.

<acronym title="...">HTML</acronym>
<ins> y <del>

Indican texto agregado o eliminado en revisiones de documentos.

<ins>Nuevo texto</ins>
<fieldset> y <legend>

Agrupan lógicamente controles de un formulario bajo un marco con título.

<fieldset><legend>Datos</legend></fieldset>
<label>

Etiqueta descriptiva vinculada formalmente a un control de formulario.

<label for="id">Nombre:</label>
