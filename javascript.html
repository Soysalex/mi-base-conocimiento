Apuntes Completos de JavaScript

Guía estructurada y exhaustiva sobre el lenguaje de programación de la web, organizada por categorías temáticas y conceptos esenciales.

¿Qué es JavaScript y para qué sirve?

JavaScript (JS) es un lenguaje de programación interpretado, ligero y de tipado dinámico, conocido principalmente como el lenguaje de scripting para páginas web. Junto con HTML y CSS, forma los tres pilares fundamentales de la tecnología de la World Wide Web.

¿Para qué sirve? Mientras HTML proporciona la estructura y CSS el diseño visual, JavaScript se encarga de la interactividad y la lógica. Permite crear contenido dinámico en las páginas, controlar multimedia, animar imágenes, validar formularios, responder a acciones del usuario (como clics y teclas) y conectar aplicaciones web con servidores en tiempo real.

1. Variables y Tipos de Datos

Las variables son contenedores para almacenar datos, y los tipos determinan qué clase de valores podemos guardar en ellas.

// Declaración moderna de variables
let nombre = "Carlos";
const anioNacimiento = 2000;
var antiguo = "Evitar usar var";
let

Declara una variable con ámbito de bloque y valor reasignable.

let edad = 25;
const

Declara una constante cuyo valor no puede ser reasignado.

const pi = 3.1416;
String (Texto)

Cadenas de caracteres delimitadas por comillas.

let texto = "Hola mundo";
Number / Boolean

Valores numéricos (enteros/decimales) y lógicos (true/false).

let activo = true;

2. Operadores y Condicionales

Herramientas para tomar decisiones en el código evaluando expresiones lógicas y comparaciones.

if / else

Ejecuta un bloque de código si una condición se cumple (true).

if (edad >= 18) { ... }
Operador Estricto (===)

Compara tanto el valor como el tipo de dato de dos variables.

if (x === 5) { ... }
Operadores lógicos

Permiten combinar condiciones (AND: &&, OR: ||, NOT: !).

if (a && b) { ... }
Operador Ternario

Una forma abreviada de escribir una estructura condicional if-else.

let r = (edad >= 18) ? "Sí" : "No";

3. Funciones

Bloques de código reutilizables diseñados para realizar tareas específicas y retornar valores procesados.

Función Declarada

Sintaxis clásica que soporta elevación (hoisting) en el script.

function sumar(a, b) { return a + b; }
Función Flecha (Arrow)

Sintaxis moderna, limpia y concisa introducida en ES6.

const multiplicar = (a, b) => a * b;
Parámetros

Valores de entrada que se le pasan a la función para operar.

function saludar(nombre) { ... }
return

Devuelve el resultado final de la ejecución de la función.

return resultado;

4. Arrays (Arreglos)

Estructuras de datos ordenadas que permiten almacenar múltiples valores en una sola variable.

Creación de Arrays

Se definen utilizando corchetes separando elementos por comas.

let frutas = ["Manzana", "Pera"];
push() / pop()

Añade elementos al final o extrae el último elemento del array.

frutas.push("Uva");
map()

Transforma cada elemento del array devolviendo un nuevo arreglo.

let dobles = nums.map(n => n * 2);
filter()

Filtra elementos que cumplan una condición específica.

let altos = pers.filter(p => p.edad > 18);

5. Objetos

Colecciones de pares de clave-valor (propiedades y métodos) que modelan entidades del mundo real.

Sintaxis de Objeto

Se definen mediante llaves con propiedades clave-valor.

let user = { id: 1, name: "Ana" };
Acceso por punto (.)

Forma habitual de consultar o modificar propiedades de un objeto.

console.log(user.name);
Métodos en objetos

Funciones almacenadas como propiedades dentro de un objeto.

let obj = { saludar() { return "Hola"; } };
Destructuring

Técnica moderna para extraer propiedades de objetos fácilmente.

const { name, id } = user;

6. Estructuras de Repetición (Loops)

Mecanismos para automatizar la ejecución repetitiva de un bloque de código bajo condiciones específicas.

Ciclo for clásico

Itera un número determinado de veces controlado por un contador.

for (let i = 0; i < 5; i++) { ... }
forEach()

Método moderno de los arrays para recorrer cada elemento.

frutas.forEach(f => console.log(f));
for...of

Recorre directamente los valores iterables como arrays o strings.

for (let f of frutas) { ... }
while

Ejecuta un bloque mientras una condición lógica se mantenga verdadera.

while (x > 0) { x--; }

7. DOM (Document Object Model)

Interfaz de programación que permite a JavaScript interactuar, modificar y manipular elementos HTML del documento.

getElementById / Query

Selecciona elementos del HTML desde el script.

let btn = document.querySelector("#miBoton");
textContent / innerHTML

Modifica el contenido de texto o código HTML interno de un elemento.

el.textContent = "Nuevo texto";
classList.add / remove

Gestiona dinámicamente las clases CSS de un elemento HTML.

el.classList.add("activo");
createElement

Crea nuevos elementos HTML de manera dinámica desde JavaScript.
