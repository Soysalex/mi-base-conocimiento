Apuntes Completos de CSS

Guía estructurada y exhaustiva sobre hojas de estilo en cascada, organizada por categorías temáticas y propiedades esenciales de diseño web.

¿Qué es CSS y para qué sirve?

CSS (Cascading Style Sheets u Hojas de Estilo en Cascada) es el lenguaje de diseño gráfico utilizado para definir y crear la presentación de un documento estructurado escrito en HTML. Mientras HTML construye el esqueleto, CSS se encarga de darle vida, color, estilo y adaptabilidad visual.

¿Para qué sirve? Permite controlar el diseño visual de múltiples páginas web a la vez, gestionar colores, tipografías, espaciados, animaciones y adaptar el contenido a diferentes tamaños de pantalla (dispositivos móviles, tablets y computadoras) mediante diseños responsivos.

1. Sintaxis y Selectores

La base para conectar las reglas de estilo con los elementos HTML específicos del documento mediante selectores de etiqueta, clase o ID.

/* Estructura básica de una regla CSS */
selector {
    propiedad: valor;
}
Selector de Elemento

Aplica estilos a todas las etiquetas HTML del tipo especificado.

p { color: white; }
Selector de Clase (.)

Aplica estilos a cualquier elemento que contenga el atributo class.

.mi-clase { background: #000; }
Selector de ID (#)

Aplica estilos a un elemento único e irrepetible en la página.

#principal { width: 100%; }
Selector Descendiente

Selecciona elementos que están dentro de otros contenedores.

div p { font-size: 16px; }

2. Modelo de Caja (Box Model)

Concepto fundamental que determina cómo se estructuran las dimensiones, márgenes y espacios de cada elemento en la interfaz.

width / height

Define el ancho y alto del contenido interno de la caja.

width: 300px; height: 150px;
padding

Espacio de relleno interno situado entre el contenido y el borde.

padding: 1rem 2rem;
border

Línea perimetral que delimita el borde exterior del relleno.

border: 1px solid #222;
margin

Espacio de separación exterior que separa el elemento de otros.

margin: 0 auto;

3. Tipografía y Textos

Propiedades orientadas al diseño de fuentes, tamaños, pesos y alineación de los bloques textuales.

font-family

Establece la familia tipográfica o pila de fuentes del texto.

font-family: sans-serif;
font-size

Define el tamaño de la fuente (px, rem, em, %).

font-size: 1.1rem;
font-weight

Controla el grosor o peso de los caracteres tipográficos.

font-weight: 600;
text-align / line-height

Alineación del texto y altura de línea para legibilidad.

text-align: center; line-height: 1.6;

4. Colores y Fondos

Herramientas visuales para aplicar tonalidades a textos, fondos sólidos o imágenes decorativas.

color

Modifica el color del texto o elementos de primer plano.

color: #ededed;
background-color

Establece el color de fondo de un contenedor.

background-color: #121212;
background-image

Permite cargar imágenes como fondo de pantalla o contenedor.

background-image: url('img.jpg');
opacity

Controla el nivel de transparencia global de un elemento.

opacity: 0.85;

5. Posicionamiento y Layout

Propiedades para alterar el flujo normal de los elementos en el documento web.

position: static / relative

Flujo predeterminado o desplazamiento relativo a su posición original.

position: relative; top: 10px;
position: absolute

Posiciona el elemento en relación a su contenedor padre más cercano.

position: absolute; right: 0;
position: fixed / sticky

Fija elementos en la ventana del navegador al hacer scroll.

position: sticky; top: 0;
z-index

Controla la profundidad y el orden de apilamiento en el eje Z.

z-index: 10;

6. Flexbox

Modelo de diseño unidimensional altamente eficiente para alinear y distribuir espacios entre elementos.

display: flex

Activa el contenedor flexible para sus elementos hijos.

display: flex;
justify-content

Alinea los elementos horizontalmente (eje principal).

justify-content: space-between;
align-items

Alinea los elementos verticalmente (eje transversal).

align-items: center;
flex-direction

Define la dirección principal del flujo (row o column).

flex-direction: column;

7. Grid Layout

Sistema de diseño bidimensional basado en filas y columnas para estructuras web complejas.

display: grid

Convierte al contenedor en una cuadrícula CSS.

display: grid;
grid-template-columns

Define el número y tamaño de las columnas de la cuadrícula.

grid-template-columns: repeat(3, 1fr);
gap

Establece el espacio de separación entre celdas o elementos.

gap: 1.5rem;
grid-column

Permite que un elemento ocupe múltiples columnas.

grid-column: 1 / -1;

8. Media Queries y Responsividad

Técnicas esenciales para adaptar los diseños visuales según las características del dispositivo o pantalla.

@media screen

Aplica reglas CSS específicas basadas en el ancho del viewport.

@media (max-width: 768px) { ... }
max-width / min-width

Puntos de interrupción (breakpoints) para resoluciones clave.

min-width: 1024px;
Units: rem, em, %

Unidades relativas recomendadas para diseños adaptativos.

font-size: 1rem; width: 100%;
clamp() / min() / max()

Funciones matemáticas CSS para tipografías y tamaños fluidos.

font-size: clamp(1rem, 2.5vw, 2rem);
